# Бот школьной столовой для MAX

Бот собирает заказы родителей на следующий учебный день и после дедлайна отправляет
Excel-отчёты создателю и преподавателям.

## Как это работает

- родитель выбирает один из двух классов и вводит ФИО ребёнка;
- в заданное время бот предлагает выбрать завтрак, обед, оба варианта или ничего;
- не ответившим приходит напоминание;
- до дедлайна выбор можно изменить;
- создатель получает общий отчёт по обоим классам;
- преподаватель 1 получает только `CLASS_1`, преподаватель 2 — только `CLASS_2`;
- заявок на роль администратора нет: преподаватель отправляет `/id`, а создатель вручную
  записывает число в `.env`.

Если ID одного или обоих преподавателей пустые, бот продолжает работать. Общий отчёт
создателю всё равно отправляется. В пятницу заказы собираются на понедельник, выходные
пропускаются. Часовой пояс зафиксирован как `Europe/Moscow`.

## Настройка

Скопируйте пример:

```bash
cp .env.example .env
```

В `.env` нужны только эти значения:

```dotenv
MAX_BOT_TOKEN=replace_me
CREATOR_USER_ID=123456789

TEACHER_1_ID=
TEACHER_2_ID=

CLASS_1=8МК
CLASS_2=2Б
PROMPT_TIME=15:00
REMINDER_TIME=16:30
DEADLINE_TIME=17:00
```

`TEACHER_1_ID` связан с `CLASS_1`, а `TEACHER_2_ID` — с `CLASS_2`.

Если ID ещё неизвестен, оставьте поле преподавателя пустым. Преподаватель открывает бота
и отправляет `/id`. После этого впишите полученное число в нужное поле и перезапустите бот:

```bash
docker compose up --build -d
docker compose logs -f bot
```

После изменения `.env`:

```bash
docker compose up -d --force-recreate bot
```

Бот работает через Long Polling: домен и открытые порты не нужны. SQLite хранится в
Docker volume `bot-data`.

## Команды

- `/start`, `/menu` — открыть меню;
- `/id` — показать MAX user ID;
- `/report` — получить отчёт на ближайшую дату;
- `/report 2026-09-01` — получить отчёт за указанную дату;
- `/help` — краткая справка.

Команда `/report` доступна только создателю и ID преподавателей из `.env`. Создатель
получает все классы, каждый преподаватель — только назначенный ему класс.

## Разработка и тесты

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
ruff check .
pytest
```

Текущий MVP хранит одного ребёнка на один MAX-аккаунт родителя. Для реального школьного
использования подготовьте правила обработки персональных данных и резервного копирования.
